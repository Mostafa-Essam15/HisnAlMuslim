# تقرير المراجعة (Phase 0) — حصن المسلم

تاريخ المراجعة: 2026-11-06 • الإصدار المُراجَع: 2.0 (commit `838cb53`)

## 1. ملاحظة جوهرية
المواصفات المطلوبة تفترض مشروع **Flutter**، لكن المشروع الموجود فعلًا **Android أصلي (Kotlin + Jetpack Compose)**. لذلك:
- لا يوجد `flutter analyze` ولا `pubspec.yaml`؛ البدائل هنا: `./gradlew testDebugUnitTest` و`assembleDebug` (تعمل على GitHub Actions).
- التطوير يستمر على نفس المشروع بدون إعادة بناء أو تحويل إلى Flutter.

## 4. المخاطر
1. لا يوجد Android SDK في بيئة العمل؛ التحقق عبر GitHub Actions فقط، ولم يُشغَّل التطبيق على جهاز.
2. التراخيص: خطوط KFGQPC والصور مسؤولية المالك؛ ملفات الأذان من مصادر خارجية؛ بيانات أبواب الأحاديث العربية بلا ملف ترخيص.
3. `google-services.json` علني في المستودع؛ يُنصح بتقييد المفتاح بحزمة التطبيق من Google Cloud.
4. قيود الأندرويد: تجاوز الصامت/DND، شاشة الأذان الكاملة (Android 14+)، قتل الخدمات من الشركات المصنّعة.
5. التخزين `SharedPreferences` بلا مخطط ترحيل.
6. المحتوى الديني المكتوب يدويًا (أذكار/تفسير مختصر) لم يُراجَع علميًا.
