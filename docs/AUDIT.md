# تقرير المراجعة (Phase 0) — حصن المسلم

تاريخ المراجعة: 2026-11-06 • الإصدار المُراجَع: 2.0 (commit `838cb53`)

## 1. ملاحظة جوهرية
المواصفات المطلوبة تفترض مشروع **Flutter**، لكن المشروع الموجود فعلًا **Android أصلي (Kotlin + Jetpack Compose)**. لذلك:
- لا يوجد `flutter analyze` ولا `pubspec.yaml`؛ البدائل هنا: `./gradlew testDebugUnitTest` و`assembleDebug` (تعمل على GitHub Actions).
- التطوير يستمر على نفس المشروع بدون إعادة بناء أو تحويل إلى Flutter.

## 4. المخاطر التقنية
1. **لم يُبنَ المشروع ولم يُجرَّب على جهاز** حتى الآن (لا Android SDK في بيئة العمل)؛ أي خطأ compile سيظهر أول مرة في GitHub Actions.
2. **مصادر البيانات الخارجية**: ملفات الأذان من assabile.com بدون شروط استخدام صريحة؛ نص المصحف يُحمَّل من api.alquran.cloud (نص Tanzil). يلزم تأكيد الترخيص قبل النشر العام.
3. **المحتوى الديني**: الأحاديث/الأذكار/التفسير المختصر مكتوبة يدويًا ولم تُراجَع علميًا؛ لا يجوز الاعتماد عليها قبل مراجعة.
4. **قيود الأندرويد**: لا يمكن ضمان تجاوز «الصامت» أو «عدم الإزعاج» على كل الأجهزة؛ شاشة الأذان الكاملة تحتاج إذنًا على Android 14+؛ الشركات المصنّعة تقتل الخدمات في الخلفية.
5. **التخزين**: كل البيانات في `SharedPreferences` (لا مخطط ولا ترحيل)؛ أي مرحلة تحتاج استعلامات (إحصائيات، بحث) ستستفيد من Room مع ترحيل آمن.
6. **الصور الواقعية**: لا يمكن تنزيلها من بيئة العمل؛ تحتاج ملفات مرخّصة يوفّرها المالك أو تُنزَّل وقت التشغيل.
