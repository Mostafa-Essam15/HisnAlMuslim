# حصن المسلم (Android)

تطبيق أندرويد بـ Kotlin + Jetpack Compose.

## المميزات
- مواقيت الصلاة حسب موقعك (مكتبة Adhan) مع اختيار طريقة الحساب.
- الأذان يشتغل في الخلفية وقت كل صلاة (AlarmManager + Foreground Service)، ويتجدول تاني بعد إعادة تشغيل الجهاز.
- **تحميل الأذان من داخل التطبيق** (مرة واحدة ويشتغل بعدها بدون إنترنت)، مع استماع تجريبي وحذف.
- **أذان كامل أو قصير** (القصير = أول ٣٠ ثانية من الملف المحمّل).
- **١٢ مؤذن**: ٩ مصريين (محمد رفعت، عبد الباسط، مصطفى إسماعيل، الحصري، المنشاوي، شعيشع، البنا، نعينع، إسماعيل الشيخ) + الحرم المكي والمدني + مشاري العفاسي.
- تتبع الصلاة: «صليت الفرض» + السنن الرواتب والوتر، لكل يوم.
- تحديات: فروض/سنن اليوم، سلسلة ٧ و٣٠ يوم، تحديات أسبوعية.
- مع كل صلاة: حديث أو آية مع تفسير مختصر (في الشاشة وفي إشعار الأذان).
- أذكار الصباح والمساء وبعد الصلاة والنوم والعامة بعدّاد، وسبحة/استغفار.
- ٥ خلفيات إسلامية (تدرجات لونية).

## الحصول على الـ APK
المشروع فيه GitHub Actions (`.github/workflows/build.yml`): كل push على `main` بيبني الـ APK تلقائيًا وبينزله في **Releases → latest → HisnAlMuslim.apk** (وكمان في Actions → Artifacts).

أو ابنِه محليًا:
```
./gradlew assembleDebug
```
والملف بيطلع في `app/build/outputs/apk/debug/app-debug.apk`.

## مصدر ملفات الأذان
الملفات **مش مضمّنة** في المشروع. التطبيق بيحمّلها وقت التشغيل من روابط `https://www.assabile.com/download/adhan/<id>` (الكتالوج في `Muezzins.kt`). راجع شروط استخدام الموقع قبل نشر التطبيق للجمهور، أو غيّر الروابط لمصدر تملكه/مرخّص. لو مؤذن لسه متحملش، بيشتغل صوت المنبه الافتراضي.
